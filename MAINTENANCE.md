# Maintenance Commitment

This project commits to a realistic maintenance surface:

- Keep the Fuji fixture and live monitoring path compatible with supported `icm-contracts` releases used by the public demo.
- Review AvalancheGo and `icm-contracts` changes that affect Teleporter, ICTT event schemas, or registry-version behavior.
- Keep the public demo compatible with supported `icm-contracts` releases once live hosting is complete.
- Respond to reproducible issues in the public repo within the published issue-response window.

Explicit non-commitments:

- No hosted mainnet monitoring service by default.
- No guarantee of third-party deployment coverage.
- No 24/7 on-call response.
- No audit opinion, security certification, or bounty submission without manual verification.
